How WebRTC Remote Control Works

OmniCast negotiates a direct peer-to-peer WebRTC connection using Google STUN servers. Video is rendered in real time with hardware-accelerated VP8/VP9 or H.264 codecs. Mouse clicks and keyboard strokes are mapped to normalized coordinates (0.0 to 1.0) and transferred over an unordered, low-latency RTCDataChannel.

Host OS Native Control

When running on Windows with Node.js host controller active, incoming data channel events can trigger real native mouse movements and keystrokes on the host desktop.
